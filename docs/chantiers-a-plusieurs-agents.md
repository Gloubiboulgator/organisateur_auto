# Les chantiers à plusieurs agents

## Une limite d'usage coupe un agent en plein vol

Un chantier de dix agents ou plus peut buter sur une limite d'usage en plein vol. Un agent coupé
emporte tout ce qu'il n'a pas écrit.

- **Un relecteur écrit ses constats au fil de l'eau**, dans un fichier. Sa réponse finale n'en est
  que le bilan.
- **La taille s'annonce avant le lancement.** L'agent nomme le nombre d'agents, puis attend le feu
  vert de l'admin.
- **Un agent qui rejoue des tests par script tourne sur un modèle moins cher.** Le jugement garde
  le modèle fort.
- **Après une coupure, on regarde ce qui est fini avant de relancer.** Relancer un script de
  chantier peut refaire le travail déjà terminé.

> Incident fondateur. Cinquante-six agents ont été coupés par une limite d'usage. Les relecteurs
> ont perdu tous leurs constats. Au redémarrage, neuf agents de construction sont repartis alors
> que huit avaient fini.

Décidé par l'admin le 2026-10-30, par questionnaire.

## Une flotte commence par un pilote

- **Un pilote ouvre le chantier.** Un seul agent traite d'abord une petite part du travail. Sa
  sortie se mesure contre l'existant, ou contre la consigne quand rien n'existe encore.
- **La consigne porte des bornes mesurables**, comme un plafond de longueur.
- **Le travail en cours se commite dans le dépôt**, jamais dans un dossier temporaire.

> Incident fondateur. Une quarantaine d'agents ont rédigé des textes sans plafond de longueur,
> deux fois et demie plus longs que l'existant. Tout a été réécrit puis revérifié. Un pilote
> l'aurait montré pour le prix d'un seul agent.

Décidé par l'admin le 2026-10-30.
